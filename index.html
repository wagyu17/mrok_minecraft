Windowsの基本操作

  1. 1回クリックは「選ぶ」ファイルやフォルダを1回だけ押すと、青くなって選ばれます。
  2. ダブルクリックは「開く」フォルダやファイルを2回すばやく押すと開きます。開かなければ、あわてずもう一度やります。
  3. 上のバーを持つと画面を動かせるウィンドウの一番上をドラッグすると、画面の場所を変えられます。
  4. 下のタスクバーで戻る画面を見失ったら、下にあるアイコンからマイクラ、Clipchamp、エクスプローラー、このページに戻ります。
  5. エクスプローラーでファイルを探す黄色いフォルダのマークを開くと、デスクトップ、ダウンロード、ビデオ、ピクチャを探せます。

保存場所の探し方

「どこに保存されたか」を見つけられると、自分で動画やMODを扱えるようになります。3つの場所を順番に確認します。

Clipchampの動画書き出す前に「保存先」を見ます。見つからない時は、エクスプローラーで「ビデオ」「ダウンロード」「デスクトップ」を順に探します。動画は `.mp4` が多いです。
ダウンロードしたMODまず「ダウンロード」フォルダを見ます。`.zip` や `.jar` のファイルは、勝手に開かず大人に見せます。
スクリーンショット「ピクチャ」や「スクリーンショット」フォルダに入ることがあります。ゲーム内で保存した画像は、使ったアプリの保存場所も見ます。

マイクラのコマンド

コマンドは、マイクラの世界にお願いを出す言葉です。最初の `/`、スペース、数字の場所をよく見ます。長いコマンドは、1文字ずつではなく「かたまり」で読みます。

/time /time set day 朝や夜など、世界の時間を変えるコマンドです。暗くて作業しにくい時は day にします。
/effect /effect give @p speed 30 1 自分や相手に効果をつけます。`@p` は近くのプレイヤー、`30` は秒数、`1` は強さです。
/fill /fill x1 y1 z1 x2 y2 z2 stone 2つの場所の間をブロックでうめます。座標をまちがえると広く変わるので、テスト場所で使います。

コマンドを打つ前に見るところ

  1. 先頭に `/` があるか見るコマンドは `/time` のように、スラッシュから始まります。
  2. スペースで分かれているか見る`/time set day` は、`/time`、`set`、`day` の3つのかたまりです。
  3. 対象を見る`@p` は近くのプレイヤー、`@a` は全員、`@s` は自分です。
  4. /fill は小さい範囲で試す大きな範囲を一気に変えるので、最初は小さい場所で練習します。

CurseForgeでMOD導入

CurseForgeは、マイクラのMODやMODパックを探して入れる時に使います。大事なのは「マイクラのバージョン」「MODローダー」「入れた後にどこから起動するか」と、遊ぶ時に押すキーを先に見ることです。

バージョン

MODが対応している Minecraft のバージョンを見ます。合っていないと動かないことがあります。

MODローダー

Forge、Fabric、NeoForge などを見ます。MODとプロファイルの種類を合わせます。

操作キー

同じキーを使うMODがあるので、ゲーム内の「操作設定」で競合がないか確認します。

CurseForgeで見る順番

  1. 入れたいMODを決める何ができるMODなのか、1行で言えるようにします。
  2. Minecraft Versionを見る自分が遊ぶバージョンと合っているか確認します。
  3. Forge / Fabric / NeoForge を見るMODローダーが合っているか確認します。
  4. 新しいプロファイルで試す大事なワールドをこわさないように、まずテスト用ワールドで確認します。
  5. 起動場所を覚えるCurseForgeで入れたMODは、CurseForge Appのプロファイルから起動することがあります。

MOD操作の共通ルール

キーは変えられる

Escから操作設定を開き、同じキーが重なっていたら使いやすいキーへ変更します。

状態で動きが変わる

右クリック中、スニーク中、戦闘モード中など、今の状態によって同じキーの意味が変わります。

まずテストワールド

銃、魔法、装置、領域系の操作は、いつものワールドではなく練習用ワールドで試します。

競合重なりやすいキー

複数MODを同時に入れると、同じキーに別の動作が入ることがあります。

R 技切替、Prime Punchのページ切替、戦闘モード、リロード、レシピ表示などで重なりやすい。 G Prime Punchの5番技、ロックオン、簡易領域、Mekanism装備モードで重なりやすい。 M Prime Punchのステータスメニュー、反転術式、痣、魔法陣で重なりやすい。 H Prime Punchの速度ブースト、HUD、武器確認、呪霊インベントリ、Selective Displacementで重なりやすい。 V Prime Punchの4番技、メイン技、近接/ズーム、装備モード、ステップアシストで重なりやすい。 Alt と Space は回避、飛行、ジャンプ、Create操作で動きが変わります。

キーが効かない時

  1. 今の状態を見る戦闘モード中か、銃を構えているか、出血状態か、対象を見ているかを確認します。
  2. 必要なアイテムを見る弾薬、触媒、対応装備、スキル、進捗、燃料など、条件が足りないとキーを押しても動きません。
  3. 操作設定で赤い競合を見る同じキーが重なっていたら、あまり使わないMOD側を別キーにします。
  4. 短押し・長押し・組み合わせを試すV のように、通常時とエイム中で意味が変わるキーがあります。
  5. テストワールドで確認するうまくいかない時は、大事なワールドではなくテスト用ワールドで1つずつ試します。

  • エンジニアのゴーグルは、装備中に見ている機械の応力、容量、内容物などを HUD に表示します。
  • 概略図と羽根ペンは右クリックで2つの角を選択します。Ctrl + スクロールで選択範囲や空中位置を調整し、左クリックで保存します。
  • 概略図は持っている間にホログラム配置用のオーバーレイを表示します。スニークしながら右クリックすると、座標入力画面を開きます。
  • リンクコントローラーは右クリックでオン/オフ、スニーク + 右クリックで手動設定画面を開きます。レッドストーンリンク受信機に右クリックすると割り当てモードになります。
Create の道具・機械の詳しい使い方

Create は「動力源で回転を作る」「シャフトや歯車で回転を運ぶ」「ベルトやファンでアイテムを動かす」「加工機械に接続する」という順番で組むと理解しやすいです。

動力の基本
  1. 水車、風車、蒸気エンジン、ハンドクランクなどで回転力を作ります。
  2. 回転している面にシャフトを接続して、回転を直線方向へ伸ばします。
  3. 歯車、ギアボックス、ベルトで回転方向や場所を変えます。
  4. メカニカルプレス、ミキサー、ソー、ドリル、ファンなどの加工機械へ接続します。
  5. 機械が止まる場合は、エンジニアのゴーグルで応力不足や過負荷を確認します。
シャフト

シャフトは Create の一番基本になる動力伝達ブロックです。

  • 回転しているブロックの軸方向に接続すると、同じ方向へ回転を伝えます。
  • 水車や風車の中心からシャフトを伸ばすと、近くの機械へ動力を渡せます。
  • シャフト同士は一直線に並べるとそのままつながります。
  • 別方向へ曲げたい場合は、歯車やギアボックスを挟みます。
  • 見た目や当たり判定を整えたい場合は、ケース入りシャフトにできます。

よく使う形は 水車 -> シャフト -> メカニカルプレス、または 水車 -> シャフト -> メカニカルベルト です。

歯車 / 大きな歯車 / ギアボックス

歯車は、シャフトの向きや回転速度を変えるために使います。

  • 小さな歯車同士を横に噛み合わせると、回転方向が反転します。
  • 大きな歯車と小さな歯車を噛み合わせると、回転速度を上げたり下げたりできます。
  • ギアボックスは回転を90度曲げたいときに便利です。
  • 垂直ギアボックスは、縦方向と横方向の動力をきれいにつなぐときに使います。
  • クラッチはレッドストーン入力で動力を切断します。
  • ギアシフトはレッドストーン入力で回転方向を反転させます。
  • シーケンスギアシフトは、一定角度だけ回す、往復させるなどの決まった動作を作るときに使います。

「方向が逆で機械が思った向きに動かない」ときは、歯車を1つ挟むかギアシフトを使うと直せます。

シャフト + メカニカルベルト

メカニカルベルトは、2本のシャフトをセットで使うアイテム搬送装置です。

  1. まずシャフトを2本、同じ向きで平行に置きます。水平ベルトでも縦ベルトでも、2本のシャフトの向きがそろっている必要があります。
  2. メカニカルベルトを持って、片方のシャフトからもう片方のシャフトへベルトを張ります。
  3. どちらかのシャフトに動力を入れると、ベルトが回ります。
  4. ベルトの上に置かれたアイテムやエンティティは、ベルトの進行方向へ運ばれます。
  5. 進行方向を変えたい場合は、入力しているシャフトの回転方向を反転させます。

ベルト単体では自動搬入・自動搬出まではできません。チェストから出す、チェストへ入れる、仕分ける、といった処理にはファンネル、トンネル、シュート、デポを組み合わせます。

よく使う形は チェスト -> ファンネル -> ベルト -> ファンネル -> チェスト です。

ファンネル / 真鍮ファンネル / トンネル

ファンネルは、チェストやベルトからアイテムを出し入れするための部品です。

  • ベルトの横や上に付けると、ベルトへアイテムを出したり、ベルト上のアイテムを回収したりできます。
  • チェストや樽に付けると、そのインベントリから搬出、またはインベントリへ搬入できます。
  • 向きが違うと出し入れが逆になるので、レンチで向きを調整します。
  • 真鍮ファンネルはフィルターや数量指定など、より細かい搬送制御に向いています。
  • トンネルはベルト上のアイテムを分配したり、複数ラインをまとめたりするときに使います。

ベルトラインを作るときは、まずベルトで流れを作り、次にファンネルで「どこから出すか」「どこへ入れるか」を決めると組みやすいです。

シュート

シュートは、アイテムを縦方向に落としたり持ち上げたりするための搬送部品です。

  • 下方向へは重力でアイテムを落とせます。
  • インベントリの下に置くと、アイテムを下へ送る縦搬送として使えます。
  • ベルトの終点や加工機械の出口から、下のチェストへ落とす用途に向いています。
  • スマートシュートはフィルターや制御が必要な場面で使います。
デポ

デポは、アイテムを1個ずつ置いて加工するための台です。

  • メカニカルプレスの下に置くと、板材や圧縮加工に使えます。
  • メカニカルソー、デプロイヤー、ファン処理などの待機場所としても使えます。
  • ベルトよりも「1個を確実に加工したい」場面に向いています。
メカニカルプレス

メカニカルプレスは、上から押しつぶす加工機です。

  1. デポまたは鉢の真上にメカニカルプレスを置きます。
  2. プレスにシャフトで回転を入力します。
  3. デポにインゴットを置くと板材へ加工します。
  4. 鉢を使うと圧縮や一部レシピの加工ができます。
  5. ベルトでアイテムを流す場合は、プレスの下を通るようにベルトを配置します。

よく使う形は 水車 -> シャフト -> メカニカルプレス と ベルト -> プレス下 -> ベルト です。

メカニカルミキサー / 鉢 / ブレイズバーナー

メカニカルミキサーは、鉢の中身を混ぜる加工機です。

  1. 鉢を置き、その真上にメカニカルミキサーを置きます。
  2. ミキサーへシャフトで動力を入れます。
  3. 鉢に材料を入れると混合レシピが進みます。
  4. 加熱が必要なレシピでは、鉢の下にブレイズバーナーを置きます。
  5. ブレイズバーナーに燃料を与えると加熱状態になり、より高度なレシピが使えます。

基本セットは ブレイズバーナー -> 鉢 -> メカニカルミキサー の縦3段です。

石臼 / 破砕ホイール

石臼と破砕ホイールは、鉱石や素材を粉砕する加工機です。

  • 石臼は単体で使いやすい初期の粉砕機です。上からアイテムを入れ、回転を入力すると粉砕します。
  • 破砕ホイールは2つを向かい合わせに置き、互いに逆向きに回すことで中央を通るアイテムを砕きます。
  • 破砕ホイールはベルトやシュートと組み合わせると自動化しやすいです。

よく使う形は チェスト -> ファンネル -> ベルト -> 破砕ホイール -> ベルト -> チェスト です。

ケース入りファン（エンケーストファン）

ケース入りファンは、風でアイテムやエンティティを押したり、素材を加工したりします。

  • シャフトで回転を入力すると風を出します。
  • 回転方向によって、押し出しと吸い込みが変わります。
  • 水を通した風は洗浄、溶岩や火を通した風は加熱系、特殊なブロックを通した風は変換系の加工に使えます。
  • ベルト上やデポ上のアイテムに風を当てると、対応する加工が進みます。

洗浄ラインの例は 破砕済み鉱石 -> ベルト -> 水越しのファン -> 回収用ファンネル です。

メカニカルソー / メカニカルドリル

メカニカルソーとメカニカルドリルは、設置したブロックや流れてくる素材を破壊・加工する機械です。

  • メカニカルソーは原木の加工、木材処理、前方のブロック破壊に使います。
  • メカニカルドリルは石や鉱石などの掘削に使います。
  • どちらも回転方向と設置向きが重要なので、レンチで向きを調整します。
  • からくりに取り付けると、自動採掘機や伐採機の先端として使えます。
デプロイヤー

デプロイヤーは、プレイヤーの手の操作を機械で再現する装置です。

  • 手に持たせたアイテムで右クリック操作や左クリック操作を行えます。
  • レンチや設定画面で動作モードを切り替えられます。
  • フィルターを設定すると、特定アイテムだけを対象にできます。
  • 苗木の植え付け、骨粉使用、アイテムの設置、加工補助などに使えます。
  • からくりに載せると、移動しながら設置や使用を行う機械になります。
スパウト / アイテム排液口 / 液体パイプ

液体を使う加工は、スパウト、アイテム排液口、ポンプ、パイプを組み合わせます。

  • スパウトは、上のタンクやパイプから液体を受け取り、下のアイテムへ注ぎます。
  • アイテム排液口は、液体入りアイテムから液体を抜きます。
  • メカニカルポンプはパイプ内の液体を押し流します。
  • ホースプーリーは大きな液体源を吸い上げたり、液体を放出したりします。

よく使う形は タンク -> パイプ -> ポンプ -> スパウト -> ベルト上のアイテム です。

メカニカルアーム

メカニカルアームは、複数の搬入元と搬出先を行き来してアイテムを運ぶ機械です。

  • デポ、ベルト、チェスト、ファンネルなどを対象にして、アイテムを拾う場所と置く場所を設定します。
  • 設定した対象の間をアームが自動で往復します。
  • レンチや設定操作で、順番に配る、空いている場所へ配るなどの動作を調整できます。
  • フィルター付きの搬出先と組み合わせると、簡単な仕分け装置になります。

大量搬送はベルト、複数地点への振り分けはメカニカルアームが向いています。

超粘着剤 / シャーシ / からくり

からくりは、複数ブロックをまとめて動かす仕組みです。

  • 超粘着剤は、隣接ブロックをからくりとしてまとめるために使います。
  • リニアシャーシは直線方向にブロックをまとめます。
  • ラジアルシャーシは周囲のブロックをまとめます。
  • メカニカルベアリングは、まとめた構造物を回転させます。
  • メカニカルピストンは、ピストン延長ポールと一緒に直線移動させます。
  • ローププーリーは、構造物を上下に動かします。
  • ガントリーシャフトとガントリーキャリッジは、長距離の直線移動に向いています。

伐採機や採掘機を作る場合は、シャーシ -> ドリル/ソー -> ポータブルストレージインターフェース -> 動力源 の流れで考えると組みやすいです。

ポータブルストレージインターフェース

ポータブルストレージインターフェースは、動くからくりと固定設備の間でアイテムを受け渡すために使います。

  1. からくり側にポータブルストレージインターフェースを取り付けます。
  2. 固定設備側にも向かい合うように設置します。
  3. からくりが近づくと、両方のインターフェースが接続されます。
  4. 接続中にチェストやベルトへアイテムを移動できます。
  5. 液体用にはポータブルフルイドインターフェースを使います。

動く採掘機の回収口、列車や移動倉庫の荷下ろし口として重要です。

レッドストーンリンク / リンクコントローラー

レッドストーンリンクは、同じ周波数同士でレッドストーン信号を送受信します。

  • 送信側と受信側に同じアイテムを入れて周波数を合わせます。
  • リンクコントローラーは、6つのボタンに周波数を割り当てて遠隔操作できます。
  • 右クリックでコントローラーをオン/オフします。
  • スニーク + 右クリックで手動設定画面を開きます。
  • レッドストーンリンク受信機を右クリックすると、コントローラーのボタンへ割り当てできます。

離れた場所のクラッチ、ギアシフト、ドア、採掘機の起動停止などに向いています。

概略図 / 概略図と羽根ペン / 概略図砲

建築物を保存して再配置するための道具です。

  • 概略図と羽根ペンで範囲を選択し、構造物を .nbt として保存します。
  • 右クリックで角を選び、Ctrl + スクロールで位置や範囲を調整します。
  • 保存した概略図を持つと、配置用のホログラムを表示できます。
  • 概略図砲に必要素材を入れると、ホログラムに沿って自動建築できます。

大きな装置を別ワールドや別拠点へコピーしたいときに便利です。

設定画面をゲーム内で開くには、別 mod の Cloth Config API が必要です。入っていない場合、Alt + T を押すと導入案内が表示されます。

基本の遊び方

  1. ガンスミステーブルを作る
  2. ガンスミステーブルで銃、弾薬、アタッチメントを作る
  3. 銃と対応弾薬をインベントリに入れる
  4. 銃を手に持って R でリロードする
  5. 右クリックで狙う
  6. 左クリックで撃つ
  7. 必要に応じて G で射撃モードを切り替える
  8. Z でアタッチメントを付け替える

スコープとズーム

スコープを付けた銃で右クリックして ADS した状態で V を押すと、ズーム倍率を切り替えられます。

ADSしていない状態で V を押すと近接攻撃になるため、ズームしたい時は必ず右クリックで構えてから押します。

インタラクトキー

銃を持っていると右クリックが ADS に使われるため、チェストや作業台などを普通に開きづらい場合があります。

その時は O を押します。対象に照準を合わせた状態で O を押すと、銃を持ったままインタラクトできます。

主な対応対象:

種類例

画面中央に「キーを押してインタラクト」と表示される場合があります。

伏せ

C を押すと伏せられます。

初期設定では C を押している間だけ伏せます。銃側が伏せに対応していない場合や、サーバー設定で伏せが無効の場合は使えません。

補足

TaCZ のデフォルト銃パックは、ゲーム起動時に上書きされる場合があります。銃パックを編集する場合は、.minecraft/tacz 内の tacz-pre.toml で DefaultPackDebug を有効にする必要があります。上書きされた場合、バックアップは .minecraft/tacz_backup に保存される可能性があります。

Prime Punch Patch キー割り当てと操作方法

解析元

primepunchpatch.jar の PrimepunchModKeyMappings、各キーの Message、押下時に呼ばれる Procedure、画面オーバーレイ、言語ファイルを逆コンパイルして確認した内容です。依存ライブラリ側はアニメーション、エフェクト、サイズ変更、モデル表示の補助が中心で、このフォルダ内で Prime Punch 用に追加されている主要キーは下の8個です。

基本操作の流れ

  1. 種族または格闘スタイルのアイテムを右クリックして、使う系統をセットします。
  2. R で種族技ページと格闘スタイル技ページを切り替えます。
  3. 画面下部の表示を見ながら Z、X、C、V、G で技を発動します。
  4. クールダウン中、レベル不足、スタン中は技が出ません。
  5. レベルアップなどで得たステータスポイントは M のメニューから Strength / Health に振ります。

クールダウンの見方

  • 種族技ページでは racecd1 から racecd5 が使われ、Cd1 から Cd5 のオーバーレイが表示されます。
  • 格闘スタイル技ページでは fightstylecd1 から fightstylecd5 が使われ、Fscd1 から Fscd5 のオーバーレイが表示されます。
  • Z は1番、X は2番、C は3番、V は4番、G は5番のクールダウンに対応します。
  • H の移動速度ブーストは、技スロットとは別に COOLDOWN_1 効果を使って再使用を制限しています。

ステータスメニュー

M を押すと StatmenuScreen が開きます。表示される主な項目は Rank、Level、XP、Health、Strength、Stat Points です。

  • Strength の add ボタンは、ステータスポイントを1消費して攻撃力計算用の内部値を増やします。
  • Health の add ボタンは、ステータスポイントを1消費して healthstat を増やし、最大体力系の強化と回復系効果を付け直します。
  • ステータスポイントが0以下の場合、ボタンを押しても加算されません。

キー競合の注意

この mod は Z、X、C、V、G、R、H、M をまとめて使うため、他の戦闘系 mod とかなり競合しやすいです。

  • R は Epic Fight、JujutsuCraft、JEI のレシピ表示などと競合しやすいです。
  • G は Epic Fight のロックオン、Curios、ProjectE などと競合しやすいです。
  • M は JujutsuCraft 系の変身 / 特殊効果キーと競合しやすいです。
  • C、V、X は JujutsuCraft、ProjectE、ParCool などと競合しやすいです。
  • H は JujutsuCraftV の Curios スロット操作と競合しやすいです。

複数 mod を同時に遊ぶ場合は、Minecraft の「操作設定」から Prime Punch 側か他 mod 側のどちらかを別キーへ移すのがおすすめです。Prime Punch のキー名は言語ファイル上では Z、X、C、V、G、M、R、H のようにそのまま表示されます。

銃の基本操作

  1. 銃と対応する弾薬を用意します。
  2. 左クリックで射撃します。
  3. R で強制リロードします。
  4. 武器によっては右クリック側に別アクションが設定されている場合があります。

両手に銃を持っている場合、R の強制リロードはリロード可能な銃を選びます。両方リロード可能な場合は、弾薬割合が低い側を優先する処理があります。

防具・補助機能

  • N は、装備にナイトビジョン系の防具ボーナスがあるときだけ意味があります。
  • V は、対応装備のステップアシストを有効/無効にします。
  • B はセーフモードの切り替えです。サーバーや設定で unsafe mode が禁止されている場合は、オフにしても自動的にオンへ戻されます。

ジェットパック

  • J でジェットパック機能を有効/無効にします。
  • 有効状態で Space を押すと上昇・ブーストします。
  • 燃料や耐久がない場合は動作しません。
  • ジャンプキーを押している最中に J を押した場合、内部的にジャンプ状態を解除する処理があります。

注意点

  • GUI 用に HUD アイコン切り替え処理は存在しますが、この jar の TGKeybinds では独立したキーバインドとして登録されていませんでした。
  • R は多くの銃 mod や戦闘 mod と競合します。
  • V は TaCZ の近接/ズーム、JujutsuCraft のメイン技、ProjectE のチャージと競合しやすいです。
  • B は Jujutsu Kasien Addon の 0.2s domain と競合します。

配布ワールドは、ほかの人が作ったワールドをダウンロードして遊ぶものです。最初に「統合版かJava版か」「ファイルがどこに保存されたか」「どうやってマイクラに入れるか」を見ます。

版を見る

統合版/BE向けか、Java版向けかを確認します。自分のマイクラと違う版だと遊べません。

保存場所

ダウンロードしたファイルは、まず「ダウンロード」フォルダで探します。

形式を見る

配布ワールドを入れる時の順番

  1. ワールドの説明を読む何をするワールドか、対応しているマイクラの版とバージョンを見ます。

  4. Java版はフォルダの場所に注意するJava版のワールドは、解凍や保存場所の確認が必要なことがあります。わからなければ大人に聞きます。
  5. 入れた後はワールド一覧を見るマイクラを開いて、ワールド一覧に追加されているか確認します。
