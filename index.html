Windowsの基本操作

  1. 1回クリックは「選ぶ」ファイルやフォルダを1回だけ押すと、青くなって選ばれます。
  2. ダブルクリックは「開く」フォルダやファイルを2回すばやく押すと開きます。開かなければ、あわてずもう一度やります。
  3. 上のバーを持つと画面を動かせるウィンドウの一番上をドラッグすると、画面の場所を変えられます。
  4. 下のタスクバーで戻る画面を見失ったら、下にあるアイコンからマイクラ、OBS Studio、CapCut、エクスプローラー、このページに戻ります。
  5. エクスプローラーでファイルを探す黄色いフォルダのマークを開くと、デスクトップ、ダウンロード、ビデオ、ピクチャを探せます。

保存場所の探し方

「どこに保存されたか」を見つけられると、自分で動画やMODを扱えるようになります。3つの場所を順番に確認します。

CapCutの動画書き出す前に「保存先」を見ます。見つからない時は、エクスプローラーで「ビデオ」「ダウンロード」「デスクトップ」を順に探します。動画は `.mp4` が多いです。
ダウンロードしたMODまず「ダウンロード」フォルダを見ます。`.zip` や `.jar` のファイルは、勝手に開かず大人に見せます。
スクリーンショット「ピクチャ」や「スクリーンショット」フォルダに入ることがあります。ゲーム内で保存した画像は、使ったアプリの保存場所も見ます。

マイクラのコマンド

コマンドは、マイクラの世界にお願いを出す言葉です。最初の `/`、スペース、数字の場所をよく見ます。長いコマンドは、1文字ずつではなく「かたまり」で読みます。

/time /time set day 朝や夜など、世界の時間を変えるコマンドです。暗くて作業しにくい時は day にします。
/effect /effect give @p speed 30 1 自分や相手に効果をつけます。`@p` は近くのプレイヤー、`30` は秒数、`1` は強さです。
/fill /fill x1 y1 z1 x2 y2 z2 stone 2つの場所の間をブロックでうめます。座標をまちがえると広く変わるので、テスト場所で使います。

コマンドを打つ前に見るところ

  1. 先頭に `/` があるか見るコマンドは `/time` のように、スラッシュから始まります。
  2. スペースで分かれているか見る`/time set day` は、`/time`、`set`、`day` の3つのかたまりです。
  3. 対象を見る`@p` は近くのプレイヤー、`@a` は全員、`@s` は自分です。
  4. /fill は小さい範囲で試す大きな範囲を一気に変えるので、最初は小さい場所で練習します。

CurseForgeでMOD導入

CurseForgeは、マイクラのMODやMODパックを探して入れる時に使います。大事なのは「マイクラのバージョン」「MODローダー」「入れた後にどこから起動するか」と、遊ぶ時に押すキーを先に見ることです。

バージョン

MODが対応している Minecraft のバージョンを見ます。合っていないと動かないことがあります。

MODローダー

Forge、Fabric、NeoForge などを見ます。MODとプロファイルの種類を合わせます。

操作キー

同じキーを使うMODがあるので、ゲーム内の「操作設定」で競合がないか確認します。

CurseForgeで見る順番

  1. 入れたいMODを決める何ができるMODなのか、1行で言えるようにします。
  2. Minecraft Versionを見る自分が遊ぶバージョンと合っているか確認します。
  3. Forge / Fabric / NeoForge を見るMODローダーが合っているか確認します。
  4. 新しいプロファイルで試す大事なワールドをこわさないように、まずテスト用ワールドで確認します。
  5. 起動場所を覚えるCurseForgeで入れたMODは、CurseForge Appのプロファイルから起動することがあります。

MOD操作の共通ルール

キーは変えられる

Escから操作設定を開き、同じキーが重なっていたら使いやすいキーへ変更します。

状態で動きが変わる

右クリック中、スニーク中、戦闘モード中など、今の状態によって同じキーの意味が変わります。

まずテストワールド

銃、魔法、装置、領域系の操作は、いつものワールドではなく練習用ワールドで試します。

競合重なりやすいキー

複数MODを同時に入れると、同じキーに別の動作が入ることがあります。

R 技切替、Prime Punchのページ切替、戦闘モード、リロード、レシピ表示などで重なりやすい。 G Prime Punchの5番技、ロックオン、簡易領域、Mekanism装備モードで重なりやすい。 M Prime Punchのステータスメニュー、反転術式、痣、魔法陣で重なりやすい。 H Prime Punchの速度ブースト、HUD、武器確認、呪霊インベントリ、Selective Displacementで重なりやすい。 V Prime Punchの4番技、メイン技、近接/ズーム、装備モード、ステップアシストで重なりやすい。 Alt と Space は回避、飛行、ジャンプ、Create操作で動きが変わります。

キーが効かない時

  1. 今の状態を見る戦闘モード中か、銃を構えているか、出血状態か、対象を見ているかを確認します。
  2. 必要なアイテムを見る弾薬、触媒、対応装備、スキル、進捗、燃料など、条件が足りないとキーを押しても動きません。
  3. 操作設定で赤い競合を見る同じキーが重なっていたら、あまり使わないMOD側を別キーにします。
  4. 短押し・長押し・組み合わせを試すV のように、通常時とエイム中で意味が変わるキーがあります。
  5. テストワールドで確認するうまくいかない時は、大事なワールドではなくテスト用ワールドで1つずつ試します。

LLL
IBI
I I

L は原木、I は鉄インゴット、B は鉄ブロックです。

銃の使い方

銃を手に持つと、通常の右クリック操作が ADS に使われます。

操作 方法
撃つ 左クリック
狙う 右クリック長押し
リロード R
射撃モード変更 G
武器を見る H
カスタマイズ Z

弾薬がない、または銃に対応していない弾薬しか持っていない場合はリロードできません。

アタッチメント

銃を持って Z を押すと、カスタマイズ画面を開けます。

どのアタッチメントがどの銃に付くかは、TaCZ_アタッチメント対応表.md を参照してください。

取り付けできる主なアタッチメント:

種類 内容
スコープ / サイト 照準器、ズーム倍率の変更
マズル サプレッサー、ブレーキなど
ストック 反動や操作性の調整
グリップ 腰撃ち精度や反動の調整
レーザー 照準補助
拡張マガジン 装弾数を増やす

カスタマイズ画面では、ダメージ、RPM、装弾数、反動、ADS、弾速、重量などの性能も確認できます。

スコープとズーム

スコープを付けた銃で右クリックして ADS した状態で V を押すと、ズーム倍率を切り替えられます。

ADSしていない状態で V を押すと近接攻撃になるため、ズームしたい時は必ず右クリックで構えてから押します。

インタラクトキー

銃を持っていると右クリックが ADS に使われるため、チェストや作業台などを普通に開きづらい場合があります。

その時は O を押します。対象に照準を合わせた状態で O を押すと、銃を持ったままインタラクトできます。

主な対応対象:

種類 例
ブロック チェスト、作業台、かまど、金床、ベッド、ドア、レバー、ガンスミステーブルなど
エンティティ 村人、行商人、馬、ラバ、ボート、トロッコ、額縁など

画面中央に「キーを押してインタラクト」と表示される場合があります。

伏せ

C を押すと伏せられます。

初期設定では C を押している間だけ伏せます。銃側が伏せに対応していない場合や、サーバー設定で伏せが無効の場合は使えません。

弾薬箱

弾薬箱は弾薬をまとめて管理するアイテムです。

操作 方法
弾薬を入れる インベントリ内で弾薬箱を持ち上げ、弾薬にカーソルを合わせて右クリック
弾薬を取り出す 弾薬箱を持ち、空スロットを右クリック
クリエイティブ用弾薬箱 指定タイプの弾薬を無限供給できる
全種クリエイティブ弾薬箱 全種類の弾薬を無限供給できる

よく使う流れの早見表

なまえ できること つかいかた ちゅうい
銃を作って撃つ 初めて銃を撃つまで テーブル設置→銃と弾を作る→銃を持ってRでリロード→右クリで狙い左クリで撃つ。 弾の種類が合っていないとリロードできない。
アタッチメントを付ける 銃をカスタマイズする ガンスミスでアタッチメント作成→銃を持ってZ→対応スロットに装着→性能を見ながら調整。 対応スロットでない部品は付かない。
チェストや作業台を開く 銃を持ったままインタラクト 対象に照準を合わせて O 右クリは「狙う」に取られるため通常操作ができない。

困った時

症状 確認すること
撃てない 弾薬が入っているか、対応弾薬を持っているか確認する
リロードできない 銃と弾薬の種類が合っているか確認する
右クリックでチェストを開けない O のインタラクトキーを使う
ズームできない ADS中に V を押しているか、スコープが付いているか確認する
Alt + T で設定が開けない Cloth Config API が導入されているか確認する
伏せられない 銃が伏せ対応か、サーバー設定で伏せが有効か確認する
キーが競合する Minecraft の操作設定から TaCZ のキーを変更する

補足

TaCZ のデフォルト銃パックは、ゲーム起動時に上書きされる場合があります。銃パックを編集する場合は、.minecraft/tacz 内の tacz-pre.toml で DefaultPackDebug を有効にする必要があります。上書きされた場合、バックアップは .minecraft/tacz_backup に保存される可能性があります。

TaCZ アタッチメント対応表

TaCZ アタッチメント対応表

対象ファイル: tacz-1.20.1-1.1.8-release.jar

この一覧は、デフォルト銃パック内の data/tacz/tacz_tags/attachments/allow_attachments/*.json と、そこから参照される tacz_tags/attachments/*.json を展開して作成したものです。別の銃パックを入れている場合や、デフォルトパックを編集している場合は内容が変わります。

銃定義: 54種類（ガンスミステーブルの銃レシピ: 53種類） / アタッチメント定義: 99種類（アタッチメントレシピ: 95種類）

読み方

  • 各銃ごとに、装着可能なアタッチメントを種類別にまとめています。
  • なし は、その種類のアタッチメントがデフォルト定義上は装着できないことを示します。
  • tacz:... は内部IDです。ゲーム内表示名が似ているアタッチメントを区別したい時に使います。
  • 弾薬MODは内部的には拡張マガジン系スロットですが、見やすさのため別項目に分けています。
  • V キーのズームが効くのは、スコープ / サイトを付けてADSしている時です。

キー競合の注意

この mod は Z、X、C、V、G、R、H、M をまとめて使うため、他の戦闘系 mod とかなり競合しやすいです。

  • R は Epic Fight、JujutsuCraft、JEI のレシピ表示などと競合しやすいです。
  • G は Epic Fight のロックオン、Curios、ProjectE などと競合しやすいです。
  • M は JujutsuCraft 系の変身 / 特殊効果キーと競合しやすいです。
  • C、V、X は JujutsuCraft、ProjectE、ParCool などと競合しやすいです。
  • H は JujutsuCraftV の Curios スロット操作と競合しやすいです。

複数 mod を同時に遊ぶ場合は、Minecraft の「操作設定」から Prime Punch 側か他 mod 側のどちらかを別キーへ移すのがおすすめです。Prime Punch のキー名は言語ファイル上では Z、X、C、V、G、M、R、H のようにそのまま表示されます。

クラフターズコロニーの配布ワールド

配布ワールドは、ほかの人が作ったワールドをダウンロードして遊ぶものです。最初に「統合版かJava版か」「ファイルがどこに保存されたか」「どうやってマイクラに入れるか」を見ます。

版を見る

統合版/BE向けか、Java版向けかを確認します。自分のマイクラと違う版だと遊べません。

保存場所

ダウンロードしたファイルは、まず「ダウンロード」フォルダで探します。

形式を見る

統合版では `.mcworld`、Java版では `.zip` など、ファイル形式を見ることが大事です。

配布ワールドを入れる時の順番

  1. ワールドの説明を読む何をするワールドか、対応しているマイクラの版とバージョンを見ます。
  2. ダウンロード後に場所を見るファイルが見つからない時は、エクスプローラーで「ダウンロード」を開きます。
  3. 統合版は `.mcworld` を見る`.mcworld` ファイルは、開くとマイクラにインポートされることがあります。
  4. Java版はフォルダの場所に注意するJava版のワールドは、解凍や保存場所の確認が必要なことがあります。わからなければ大人に聞きます。

くわしい手順（OBS Studio × CapCut）

ここからは、OBS Studioで画面を録画し、CapCutで編集して、最後に書き出す（エクスポートする）までのくわしい手順です。

1. OBS Studio による画面収録

1.1 収録の準備

  1. ソースの追加「ソース」パネルの「+」ボタンをクリックします。画面全体を撮る場合は「画面キャプチャ」、特定のウィンドウのみを撮る場合は「ゲームキャプチャ」または「ウィンドウキャプチャ」を選びます。
  2. 音声の設定「音声ミキサー」でマイク（入力）とデスクトップ音声（出力）が正しく反応しているか確認します。
  3. 出力設定の確認「設定」＞「出力」＞「録画」タブを確認します。録画ファイルのパス（保存先）を確認し、録画フォーマットは編集しやすい mp4 または mkv（mkvは後でmp4に変換可能）を選びます。

1.2 収録の開始と終了

  1. 録画開始右下の「録画開始」ボタンをクリックします。
  2. 収録解説や操作を行います。
  3. 録画終了「録画終了」ボタンをクリックします。ファイルが指定したフォルダに保存されます。

2. CapCut での編集

2.1 素材のインポート

  1. プロジェクトの作成CapCut（PC版）を起動し、「新しいプロジェクト」を作成します。
  2. 動画の読み込み「インポート」ボタンをクリックし、OBSで収録した動画ファイルを選びます。
  3. タイムラインに配置インポートした素材を下の「タイムライン」にドラッグ＆ドロップします。

2.2 基本的な編集操作

  • カット編集（分割）：再生ヘッド（青い線）を切りたい位置に合わせ、Ctrl + B（分割）を押します。不要な部分を選択して Delete キーで削除します。
  • テロップ（テキスト）の追加：上部メニューの「テキスト」から好きなスタイルを選び、タイムラインに配置します。右側のパネルでフォント・サイズ・色を調整します。
  • オーディオ調整：タイムラインのクリップを選び、右側パネルの「オーディオ」から音量を調整します。ノイズがある場合は「ノイズ除去」にチェックを入れると効果的です。

3. エクスポート（書き出し）

3.1 書き出し設定

  1. エクスポートを開く右上の「エクスポート」ボタンをクリックします。
  2. タイトルと保存先動画のファイル名（タイトル）を入力し、書き出し先のフォルダを選びます。
  3. 解像度・フレームレート解像度は通常 1080p を推奨。フレームレートは収録時に合わせた設定（30fps または 60fps）を選びます。

3.2 最終確認

  1. 書き出し「エクスポート」ボタンを押し、処理が完了するまで待ちます。
  2. 再生して確認保存された動画を再生し、音声のズレや編集ミスがないか確認して完了です。

4. 【補足】YouTubeショート（9:16）向けの編集

YouTubeショートやTikTok向けに縦長動画を作成する場合の設定です。

4.1 CapCut のキャンバス設定

  1. アスペクト比を開くタイムライン上部の「アスペクト比」または「変更」をクリックします。
  2. 9:16 を選ぶ「9:16」を選択します。

4.2 レイアウトの工夫

  • 背景のぼかし：横長の動画（16:9）を中央に置くと上下に黒い隙間ができます。クリップを選び、右側パネルの「動画」＞「キャンバス」＞「ぼかし」を選ぶと、背景にぼかした映像が表示されて見栄えが良くなります。
  • テロップの位置：ショート動画では画面下部にユーザーアイコンやキャプションが重なるため、重要なテロップは画面中央からやや上寄りに配置するのがコツです。
